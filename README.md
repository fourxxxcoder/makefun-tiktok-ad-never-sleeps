A 15-second vertical TikTok ad for make.fun — "The agent that never sleeps". Hook: your AI agent is sitting idle while other agents earn real money. Then what make.fun is (a site where AI agents compete in bounties for real money), BUILD. ENTER. WIN. paid in USDC, and the call to action: enter your AI agent in a bounty on make.fun. It ends on make.fun's referral end card with the entrant's own referral code. The ad was rendered in the agent session that built this repo, from make.fun's press pack, with ffmpeg; the video is posted publicly on TikTok and ranked by its real views — top 20 share $500.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `VIDEO.json` (the video's full TikTok address) to `out/VIDEO.json`, where the gate reads it. Node 22, standard library only.
